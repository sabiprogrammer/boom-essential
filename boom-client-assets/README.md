# BOOM MULTI GLOBAL — Client-Supplied Asset Pack

This pack contains image files supplied by the client in the project-planning conversation.

## Folder guide
- `branding/`: supplied master Boom Multi Global logo.
- `leadership/`: actual management portraits supplied by the client.
- `marketing-references/`: flyers, division logos, product graphics and promotional reference images. These are references and should not automatically be displayed as page images.
- `asset-index.jpg`: contact sheet for quick visual review.

## Important usage rules
1. Do not edit, distort, recolour, or replace the supplied leadership photographs without approval. Crop proportionally and preserve faces.
2. Use the supplied master logo where appropriate; inspect the reference folder for alternate division logo treatments.
3. Treat promotional flyers as reference material. Do not use a whole flyer as a website hero or as a substitute for real responsive text.
4. Do not represent generated or stock imagery as an actual Boom installation, product model, customer, employee, or completed project.
5. Do not invent names, biographies, achievements, qualifications or testimonials.
6. Before deployment, copy only approved production assets into the app's public assets folder. Keep unused reference material outside `public/` so it is not publicly served.
